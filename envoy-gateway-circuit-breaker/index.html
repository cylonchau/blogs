BackendTrafficPolicy

断路器是指，当后端压力过大时，Envoy 主动限制继续打到后端的请求数量，让一部分请求快速失败，用于保护后端。

Envoy Gateway 支持如下断路器阈值

  • 并发连接：限制 Envoy 可以與上游服務建立的連線數。當達到此閾值時，將不會建立新連接，部分請求將被排隊，直到現有連接可用為止。
  • 并发请求：限制 Envoy 向上游服務發送的並發請求數。當達到此閾值時，請求將被排隊。
  • Pending请求：限制 Pending 請求队列的大小。當達到此閾值時，超出佇列容量的請求將被終止。 503狀態碼。

Envoy 的计数器是跟随 Envoy Proxy 实例来维护的，默认的断路器为 1024，对于高并发系统来说很容易被触发

断路器配置#

断路器配置就是根据 BackendTrafficPolicy 来配置的，然后绑定到对应的 Gatway API 上

yaml
1
2
3
4

  circuitBreaker:
    maxConnections: 0 #Envoy 到后端最多建立多少连接
    maxParallelRequests: 10 # Envoy 同时转发给后端的最大并发请求数
    maxPendingRequests: x # 并发满了以后，最多允许多少请求排队

cat <<EOF | kubectl apply -f -
---
apiVersion: gateway.networking.k8s.io/v1
kind: HTTPRoute
metadata:
  name: red-gray-circuit-route
  namespace: default
spec:
  parentRefs:
    - name: eg
  hostnames:
    - circuit.example.com
  rules:
    - matches:
        - path:
            type: PathPrefix
            value: /
      backendRefs:
        - name: envoy-end-red
          port: 90
          weight: 50
        - name: envoy-end-gray
          port: 90
          weight: 50
EOF

cat <<EOF | kubectl apply -f -
apiVersion: gateway.envoyproxy.io/v1alpha1
kind: BackendTrafficPolicy
metadata:
  name: circuitbreaker-for-red-gray-route
  namespace: default
spec:
  targetRefs:
    - group: gateway.networking.k8s.io
      kind: HTTPRoute
      name: red-gray-circuit-route
  circuitBreaker:
    maxPendingRequests: 5
    maxParallelRequests: 1
EOF
